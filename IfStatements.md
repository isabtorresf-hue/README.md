# If Statements

## 1. Concept 

If statements are used to make decisions in a program.

They allow the program to check a condition and execute different actions depending on whether the condition is true or false.

For example, a program can check if a person is old enough to vote or if a password is correct.

---

## 2. Key C# Syntax

```csharp
int age = 20;

if (age >= 18)
{
    Console.WriteLine("You can vote");
}
else
{
    Console.WriteLine("You cannot vote");
}
