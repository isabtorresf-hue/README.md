# Operators

## 1. Concept 

Operators are symbols that allow us to perform different actions with values and variables.

They can help us make calculations, compare information, and create decisions in a program.

In C#, there are different types of operators, like arithmetic operators, comparison operators, and logical operators.

---

## 2. Key C# Syntax

```csharp
int number1 = 10;
int number2 = 5;

int addition = number1 + number2;
int subtraction = number1 - number2;

Console.WriteLine(addition);
Console.WriteLine(subtraction);
