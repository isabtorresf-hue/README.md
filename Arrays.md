# Arrays

## 1. Concept 

Arrays are used to store multiple values inside one variable.

Instead of creating many different variables for each value, we can use an array to keep related information together.

Each value inside an array has a position called an index. The first index always starts at 0 in C#.

Arrays are useful when we need to work with a list of information.
