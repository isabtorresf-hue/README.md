# Loops

## 1. Concept 

Loops are used to repeat instructions in a program.

Instead of writing the same code many times, we can use a loop to repeat it automatically.

Loops are useful when we need to work with multiple values or when we want an action to happen several times.

In C#, the most common loops are `for`, `while`, and `do while`.

---

## 2. Key C# Syntax

### For Loop

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
