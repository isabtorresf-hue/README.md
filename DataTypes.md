# Data Types

## 1. Concept 

Data types define what type of information a variable can store.

In C#, every variable needs a data type because the computer needs to know what kind of value it will receive.

For example, we use numbers to store ages, text to store names, and true or false values to store information like yes or no.

Learning data types helped me understand how the program organizes information.
