# Variables

## 1. Concept for me

Variables are used to store information inside a program. They allow us to save values and use them later when we need them.

A variable has a name, a data type, and a value. For example, we can create a variable to store a person's name, age, or favorite color.

Variables are important because they make programs easier to organize and update. The value of a variable can also change while the program is running.
